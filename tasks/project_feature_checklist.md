# TeleGuard - Project Feature Checklist

High-level functional status tracking for the standalone community management and giveaway bot suite.

---

- [x] **Community Anti-Spam & Moderation Suite**: Domain/path whitelist (X/Twitter, Reddit, Facebook & short links `t.co`/`redd.it`/`fb.watch` auto-whitelisted), Unicode + Premium custom emoji spam filtering, keyword/regex blacklists, flood detection, CAS spam blocklist, topic & admin exemptions, SA Admin Telegram IDs dual-exemption (Web 2FA login + complete anti-spam bypass & moderation immunity), `/mute`, `/ban`, `/unmute`, `/unban`, `/warn` with DM receipts & live chat member verification.
- [x] **Group Captcha Verification & Welcome System**: Flexible group & topic scope designation (`captcha_communities`), multi-topic forum isolation (challenge presentation & answer interaction strictly routed to the designated topic with graceful non-forum fallback), customizable member welcome messages (`welcome_enabled`, `{mention}`/`{name}`/`{group}` templating), conditional post-verification vs. direct joining delivery, and configurable auto-deletion timer (`welcome_delete_delay_mins`).
- [x] **Dynamic Community & Topic Prompt Templating**: Intelligent context-aware dynamic templating engine (`renderCommunityTopicTemplate` & `buildTopicLink`) across all community and topic alerts (`wrong_topic_warning`, `welcome_message`, `captcha_success_msg`, `captcha_alert_success`, `captcha_welcome_msg_*`); supports `{group}`, `{topic_id}`, `{topic_link}`, `{group_link}`; Telegram General Topic (ID 1) client compatibility; 64-bit ID parsing protection (`rawId.length >= 12 && startsWith("100")`).
- [x] **Community Activity XP & Rank System**: Pure Telegram community message & reaction XP collection, anti-abuse cooldowns, Lv1-Lv100 logarithmic formulas, dynamic 600x600 PNG `/rank` card rendering with Sharp, H5 Activity Leaderboard Mini App (Weekly & All-Time periods, pure Telegram activity rankings with zero Cashbox/Invite pollution).
- [x] **Lucky Draw (Community Giveaway Suite)**: Autonomous Telegram giveaway suite with SQLite isolation (`drawbot.db`), integrated into Web Admin; Quill rich text editor for formatted event descriptions with strict Telegram HTML entity sanitization; unified card layout with status badge (`ACTIVE`, `DRAFT`, `DRAWING`, `ENDED`); one-click "Copy as Template"; draw confirmation modal with random and designated winner modes; scheduled Auto Draw; winner announcement grouping by prize tier; Beijing Time (UTC+8) standard; bot token pure SQLite persistence.
- [x] **MTProto Userbot Recent Actions Logger**: Telegram MTProto Recent Actions group audit logger (requires optional Telegram API ID/Hash/Session) for tracking administrative actions and group audit trails.
- [x] **Web Admin Dashboard & Security**: Strict dual-channel authorization (Channel 1: Master Password + enforced `ADMIN_IP_WHITELIST` check with trust-proxy/forwarded-for parsing; Channel 2: Telegram 6-digit interactive code to rankbot restricted to `SA_ADMIN_TG_IDS`), Cyber Dark theme, Community Management & Lucky Draw tabs, user activity XP adjustments, spam logs review, banned users management, admin logs audit, custom commands manager.
- [x] **Complete Cashbox Decoupling**: 100% removal of Pushbot, Remote MySQL connections (`mysql2`), Device Tracking Graph (`visitorId`, `graph.html`), Player UID (`/tg2uid`), Data Query (`/sa`), Cashbox game invites (`players.validCount`, fake invite generator).
- [x] **Bilingual Documentation (Default English & Chinese Switch)**: Top-level bilingual README suite (`README.md` in English by default with instant toggle to `README_CN.md` and vice-versa) adhering to standard GitHub open-source project conventions.
- [x] **Full-Stack UI Internationalization (i18n) & Default English Enforcement**: Zero-dependency lightweight client-side i18n engine (`public/js/i18n.js`), 100% English by default with zero initial Chinese characters across all UI pages (Login Screen, Admin Dashboard, Safety & Spam, Group Captcha, Lucky Draw modals, Leaderboard Mini App), top-right Cyber Dark language toggle button (`🌐 English` / `🌐 简体中文`) with instant DOM translation reactivity and `localStorage` persistence.
