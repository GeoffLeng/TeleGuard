📚 Safety & Anti-Spam Rules Manual

This manual documents the detailed moderation logic, detection mechanisms, and action triggers implemented by the Anti-Spam engine.

🛡️ Action Type Definitions

  • Ban: Kicks the spammer from the group and permanently bans them. They cannot re-join unless unbanned by an admin.
  • Mute: Restricts the user from sending messages, media, or links temporarily or permanently.
  • Delete Only: Removes the offending message immediately without restricting the user.

⚙️ Safety Interception Rules

1. RTLO Characters Detection

Checks for the Right-to-Left Override unicode character (\u202e). Spammers use this character to trick users by displaying file names or links backward (e.g., hiding a malicious executable file or reversing links). Recommended Action: Ban or Mute (1440 mins).

2. New Member Link Restriction

Restricts new users (Level 1 and XP < 50) from posting external links. Admin/whitelisted domains are bypassed. Banned or muted if they attempt to post links immediately after joining. Recommended Action: Mute (60 mins) or Delete Only.

3. Combot CAS Global Blacklist

Queries Combot's global anti-spam database. When a user sends their first message in the group, the bot queries the API. If they are flagged as a known spammer across Telegram, the bot executes the configured action. Recommended Action: Ban.

4. Block Inline Keyboards

Blocks messages containing custom inline buttons/keyboards sent by non-admins. Real users cannot send custom buttons in messages; this is a clear signature of automated spam bots. Recommended Action: Ban.

5. Block Messages via Inline Bots

Blocks messages sent via inline query bots (e.g. typing @gif or custom advertising bots). You can whitelist legitimate bots like gif, vote, like, poll to keep them usable. Recommended Action: Delete Only.

6. Auto-Ban Spam Keywords

Extracts the user's message, username, and nickname, normalizes Unicode (collapsing spaced-out words like "e a s y m o n e y" or stylized fonts), and checks against the comma-separated keyword list. Recommended Action: Ban or Mute (1440 mins).

7. Message Flood Control

Monitors messages per user in real-time. If a user exceeds the configured messages threshold (e.g. 5 messages) within the time window (e.g. 3 seconds), they are automatically muted for the set duration. Recommended Action: Mute (60 mins).
